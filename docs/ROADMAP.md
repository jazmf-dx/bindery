# これから足す機能

**更新日**：2026-11-25

**結論**：次の数版は **「探す」と「整理の穴埋め」** に絞る。使うのは当面自分だけなので、配布・移行まわり（運用）は後にする。全文検索とプレビューは今回の計画に入れない。

何を作るか・決めたことは [CONCEPT.md](CONCEPT.md)。ここは順番だけを書き、決めたことは作るときに CONCEPT.md へ移す。

## 前提

| 項目 | 前提 |
|---|---|
| 使う人 | 当面は自分だけ。使いながら直す |
| 優先する柱 | 探す・整理の穴埋め |
| 入れないもの | 全文検索・小さなプレビュー（下の「入れないもの」） |

## Now（0.2.0）：探せるようにする・変化に気付けるようにする

CONCEPT で「最初は名前・場所・タグ・メモで探す」と決めたのに、まだ探す手段が無い。ここを先に埋める。
あわせて、登録フォルダの中で更新・追加されたファイルに気付けるようにする。

| 機能 | 中身 | 着手時に決めること |
|---|---|---|
| 名前の絞り込み | 一覧の上に入力欄。名前（と場所）で絞る | 今の場所の中だけか、全体からか。キー（⌘F / Ctrl+F） |
| 並び替え | 列の見出しを押して、名前・場所・種類・更新日で並べ替える | 並びを覚えるか（場所ごと／全体で 1 つ） |
| メモ | 詳細パネルでファイルにメモを書く。絞り込みの対象にも入れる | 1 行か複数行か。Markdown として出すか |
| 行方不明の操作 | 行方不明のファイルを手でつなぎ直す・外す | つなぎ直す先の選び方（ファイルのダイアログ／一覧から） |
| 最近の変更 | サイドバーの特別な項目。**中身が更新されたもの**（大きさか更新日時が変わった）と **新しく増えたもの** を、新しい順に並べる。既読は持たない。気付くのは今と同じ起動時と［読み直す］のとき（常時の監視はしない） | 期間（7 日など。変えられるようにするか）。フォルダを登録したときに見つけたものは「増えた」に入れない。「更新」「新規」の違いを行に出すか |

## Next（0.3.0）：整理を手早くする

| 機能 | 中身 | 着手時に決めること |
|---|---|---|
| 右クリックのメニュー | 一覧・サイドバーの行に。中身は `commands.ts` の表から | |
| 仮想フォルダの移動 | サイドバーで仮想フォルダを別の仮想フォルダの下へドラッグ（コマンド `move_vfolder` はある） | |
| 条件の組み合わせ | タグを複数（かつ）・種類・更新日で絞る | 画面の置き場（サイドバーの複数選択か、一覧の上の条件か） |
| 外のファイルを 1 つずつ足す | 登録フォルダの外のファイルを個別に足す。今は落とすと「まだできない」と出す | データの作り（`files` の持ち方、照合のしかた）。**ADR 候補** |

## Later：使い込んでから決める

| 機能 | 中身 |
|---|---|
| 検索の保存 | 条件の組み合わせを名前を付けて残す（仮想フォルダとは別の項目） |
| 登録の選び直し | サブフォルダを含めるかを、登録し直さずに変える（今は外して登録し直す） |
| updater の鍵 | owner の鍵に替え、アプリ内アップデートを戻す（`decisions/project-context.md` の「逸脱」）。人に配るときには必須 |
| 書き出し・読み込み | 整理をほかの端末へ移す。パスが違う端末での照合 |
| 大きいフォルダ・遅い共有ドライブ | 差分だけ読む・後ろで読む |
| 設定画面 | 自動のアップデート確認を切るなど |

## 入れないもの（今回）

| 機能 | 理由 |
|---|---|
| 全文検索 | CONCEPT で後回しにした。名前・タグ・メモで探して足りないとわかってから考える |
| 詳細パネルの小さなプレビュー | 元のファイルを画面に渡すため CSP を緩める判断が要る。Quick Look で足りないとわかってから考える |
